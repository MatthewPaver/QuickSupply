  <files>src/app/api/school/reviews/route.ts</files>
  <behavior>
    - POST body with wouldRebook: true persists wouldRebook as true in schoolTeacherReviews
    - POST body with wouldRebook: false (or omitted) persists as false
    - wouldRebook is included in both INSERT path and UPDATE .set() — not just one branch
    - comment is normalised: comment?.trim() || null (empty string saved as null)
    - After every insert or update, all reviews for that teacher are fetched and agencyRating is recalculated as their mean and written to teachers table
    - Teachers with zero reviews keep agencyRating fallback 3.0 (no reviews exist at insert time so this case is moot on first insert)
    - Response body uses { ok: true } (existing — do not change to { success: true })
  </behavior>
  <action>
    Update `src/app/api/school/reviews/route.ts`:

    1. Destructure `wouldRebook` from `parsed.data` alongside `bookingId`, `rating`, `comment`. Also import `teachers` from schema and `avg` from drizzle-orm (or use manual JS average — see note below).

    2. Normalise comment: `const normalisedComment = comment?.trim() || null`

    3. In the UPDATE branch, change `.set(...)` to include:
       `{ rating, comment: normalisedComment ?? existing.comment, wouldRebook: wouldRebook ?? existing.wouldRebook, createdAt: new Date() }`

    4. In the INSERT branch, add `wouldRebook: wouldRebook ?? false` to the `.values({...})` call.

    5. After both branches (before the return), add agencyRating recalculation:
       ```typescript
       const allReviews = db
         .select({ rating: schoolTeacherReviews.rating })
         .from(schoolTeacherReviews)
         .where(eq(schoolTeacherReviews.teacherId, booking.teacherId))
         .all();

       const newAvg = allReviews.length > 0
         ? allReviews.reduce((sum, r) => sum + r.rating, 0) / allReviews.length
         : 3.0;

       db.update(teachers)
         .set({ agencyRating: newAvg })
         .where(eq(teachers.id, booking.teacherId))
         .run();
       ```

    Note: Import `teachers` at the top of the file (add to existing schema import). Use JS reduce for the average — do not import drizzle `avg()` aggregator (adds complexity for no gain).

    Note: `wouldRebook ?? existing.wouldRebook` on the UPDATE path prevents the rebook flag from resetting if a client submits without the field.
  </action>
